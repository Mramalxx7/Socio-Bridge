# SocioBridge: Jharkhand Multi-Stakeholder R&D Engine (SIH26043)

## 🚀 Overview
SocioBridge connects rural and urban citizens in Jharkhand directly with State Government Nodal Officers, premier research universities (BIT Mesra, NIT Jamshedpur), and CSR partners (Tata Steel CSR, Vedanta) to crowdsource, verify, and resolve grassroot civic challenges.

---

## 🛠️ Tech Stack & Key Features
* **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons
* **Workflow Engine:** Multi-Persona Role Switcher (Citizen, Govt Admin, University R&D, Industry CSR)
* **AI NLP Auto-Tagger:** Real-time problem category and urgency classification
* **Geo-Filtering:** Covers all 24 Jharkhand districts
