# 🚀 SocioBridge (SIH26043)
### Jharkhand Multi-Stakeholder R&D Engine

SocioBridge is a full-stack civic platform that bridges grassroots rural and urban challenges with Jharkhand Government departments, academic R&D laboratories (BIT Mesra, NIT Jamshedpur, IIT ISM), and Corporate Social Responsibility (CSR) funding partners.

---

## 🛠️ Tech Stack & Architecture
* **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
* **Backend & Database:** Supabase (Cloud PostgreSQL Database, Real-time REST API Synchronization)
* **Deployment:** Vercel

---

## ✨ Key Features & Workflows
1. **Hyper-local Crowdsourcing:** Citizens and Gram Panchayats can log civic challenges with AI-assisted category auto-tagging.
2. **Govt Verification Portal:** District Magistrates and BDOs can vet problem severity and approve entries for research.
3. **University R&D Matchmaker:** Engineering colleges can adopt verified challenges for capstone M.Tech/B.Tech research.
4. **Industry CSR Funding Portal:** Corporate partners (Tata Steel, Vedanta, etc.) can allocate direct milestone-based grants.
5. **Live Supabase Integration:** Instant multi-device synchronization and persistent cloud storage.
